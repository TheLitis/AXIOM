# AXIOM contributor instructions

Build the intended change autonomously within its requested scope. Keep commits logically scoped and use the configured author/signing. Do not create pull requests unless requested.

This is a research project: preserve exact challenge/protocol identity and source hashes, distinguish synthetic/supplied/native-verified/human-calibrated evidence, and never invent real-level AR or human-limit claims. Timing Monte Carlo uncertainty is conditional numerical error. Cohort T50 needs censoring and a compatible population/protocol reference.

Use `uv sync --locked --extra dev` and run appropriate meaningful checks. The package uses Python 3.11+ and has no runtime dependencies. Do not commit game binaries, personal telemetry, save files, credentials, reports or private source attachments. Keep public documentation in English and update README.ru.md for user-facing scope changes.
